# 课程表排版工坊

一个离线运行的课程表填写与打印工具。打开 `index.html` 即可使用，不需要安装服务端或上传课程数据。

## 适配说明

本项目的版式、字体、配色和打印比例，针对“某神秘高中”的课程表样式进行适配：保留原表格的浅蓝细线、彩色科目字、星期渐变标题、蓝绿色时间渐变，以及 A4 大版和 A4 纵向 8 联小版的打印逻辑。

这里使用“某神秘高中”作为匿名化称呼，避免在公开仓库中暴露学校或个人信息。课程内容可以在页面中直接替换，数据默认保存在浏览器本地。

## 功能

- 在线编辑星期一至星期六的课程内容。
- 保留早读、课间操、眼保健操、午休、晚饭、晚读和自习等特殊行。
- 自动保存、撤销、清空、恢复示例和 JSON 备份。
- 支持标准 JSON 导入模板和 AI 图片识别提示词。
- 内置高三、高二班级课表预设，可选择后自动填充白天课程；早读、晚读和晚自习保持统一设置。
- 导出真正的矢量 PDF：文字和线条可无损放大，渐变文字使用 PDF 绘图指令生成。
- 导出 450 DPI PNG，适合留档或送印。
- A4 横向大版，以及 A4 纵向 2 列 × 4 行小版。

## 使用

1. 双击打开 `index.html`。
2. 在左侧编辑课程；预览会自动更新。
3. PDF 打印时选择“实际大小 / 100%”，不要选择“适合页面”。
4. 需要迁移内容时，使用“备份填写内容”和“恢复备份”。

## 标准导入

- `课程表导入模板.json`：可直接填写或交给 AI 生成。
- `AI识别课表提示词.md`：与课表图片一起发送给 AI，生成可导入 JSON。
- `font-gallery.html`：独立的开源中文字体审阅页。

## 文件说明

- `index.html`、`styles.css`、`app.js`：离线网页工具。
- `assets/fonts`：从原 Word 样式中整理的字体文件。
- `vendor/pdf-lib.min.js`、`vendor/fontkit.umd.min.js`：离线矢量 PDF 依赖。
- `2-0`：原始参考 Word、PDF 和图片，仅用于版式对照。
- `presets.js`：内置班级课表预设数据。
- `output/pdf`：示例导出 PDF。

## 隐私与限制

课程内容只保存在当前浏览器的 `localStorage` 中；本工具不提供云端同步。公开仓库中的示例数据仅用于展示排版效果，请勿提交真实学生隐私信息。
