# 课程表排版工坊

双击 `index.html` 即可离线使用，无需安装、无需联网。

- 在左侧填写科目，右侧会即时按原 Word 样式渲染。
- 可导出真正矢量的 A4 横向大版 PDF、A4 纵向 8 联小版 PDF，以及对应的 450 DPI 超清 PNG。
- 8 联小版会自动移除“修改于”页脚和大版空白，仅放大表格主体并保留打印安全边距。
- 填写内容自动保存在当前浏览器中，也可以手动备份为 JSON。
- `assets/fonts` 中保留了原 Word 使用的字体，`vendor` 中保留了离线 PDF 生成库；请勿单独移动 `index.html`。

打印 PDF 时选择“实际大小 / 100%”，不要选择“适合页面”。

## 标准导入

- `课程表导入模板.json` 是可直接填写或交给 AI 生成的标准格式。
- `AI识别课表提示词.md` 可与课表图片一起发送给 AI，返回的 JSON 可直接导入页面。
- 页面也兼容此前由“备份填写内容”生成的旧版 JSON。
